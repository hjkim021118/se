## 1. 서론

### 1.1 문서 목적 및 범위
본 문서는 '클라우드 파일 공유 시스템(미니 드라이브)'의 핵심 기능 및 예외 상황에 대한 처리 방식을 정의하며, 특히 운영 안정성을 보장하기 위한 구체적인 시스템 임계치와 제약 사항을 명시하는 것을 목표로 함

### 1.2 대상 시스템 개요
#### 1.2.1 프로젝트 정의
조직 내 파일을 중앙 서버에서 관리하고, 내/외부 협력자와 안전하게 소통할 수 있는 웹 기반 협업 플랫폼

## 2. 요구사항

### 2.1 기능적 요구사항 (Functional Requirement)

#### 2.1.1 계정 및 관리 기능
| 분류 | 요구사항 | 세부 내용 및 예외 처리 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **FR-001** | 사용자 로그인 | 이메일/비번 기반 로그인. **[예외]** 로그인 5회 실패 시 30분간 계정 잠금 | 상 |
| **FR-002** | 권한 기반 접근 | **[예외]** 권한 없는 폴더/파일 접근 시 '접근 권한 없음' 안내 및 메인 화면 리다이렉트| 상 |

#### 2.1.2 파일 및 폴더 관리 기능
| 분류 | 요구사항 | 세부 내용 및 예외 처리 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **FR-003** | **파일 업로드** | **[제약]** 개별 파일 최대 **2GB** 제한. **[차단]** 실행 파일(`.exe`, `.bat`, `.sh`) 업로드 불가 | 상 |
| **FR-004** | 파일 복구 및 삭제 | 삭제된 파일은 휴지통으로 이동. **[제약]** 삭제 후 30일 경과 시 자동 영구 삭제 | 중 |

#### 2.1.3 공유 및 협업 기능
| 분류 | 요구사항 | 세부 내용 및 예외 처리 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **FR-005** | 공유 링크 관리 | 만료일 설정. **[예외]** 만료된 링크 접근 시 '만료된 링크' 안내 페이지 표시 | 상 |

### 2.2 비기능적 요구사항 (Non-Functional Requirement)

#### 1) 운영 및 성능 요구사항
| 분류 | 요구사항 | 세부 내용 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **NFR-001** | 가용성 | 200명 동시 접속 시에도 **응답 지연 시간 3초 이내** 유지 (측정 기준: TTI*)| 상 |
| **NFR-002** | 복구 지점 | 시스템 장애 발생 시 최대 24시간 이내의 데이터를 복구할 수 있는 백업 체계 유지| 상 |

> * **TTI (Time To Interactive)**: 사용자가 클릭한 시점부터 서버 응답 후 화면 조작이 가능해지는 시점까지의 왕복 시간을 기준으로 함

#### 2) 보안 요구사항
| 분류 | 요구사항 | 세부 내용 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **NFR-003** | 데이터 암호화 | 전송 중(SSL/TLS) 및 저장 중(AES-256) 데이터 암호화 필수 적용 | 상 |

---

### 2.3 인터페이스 요구사항
* **에러 메시지 표준화**: 모든 예외 상황 발생 시 이해 가능한 한글 메시지와 고유 에러 코드(예: ERR-AUTH-001) 병행 표기
* **반응형 상태 표시**: 파일 업로드 시 실시간 % 진행률을 시각화하는 Progress Bar 제공

## 3. 품질 요구사항 (Quality Requirement, ISO 25010 기반)

### 3.1 성능 효율성 (Performance Efficiency)
| ID | 품질 특성 | 요구사항 세부 내용 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **QR-001** | 시간 반응성 | 파일 검색 결과 표시 및 다운로드 시작은 요청 후 3초 이내에 완료되어야 함 | 상 |
| **QR-002** | **자원 효율성** | 200명 동시 접속 시 **서버 CPU 사용률 70%, 메모리 사용률 80% 이하** 유지 | 상 |

### 3.2 보안성 (Security)
| ID | 품질 특성 | 요구사항 세부 내용 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **QR-003** | 기밀성 | 모든 데이터 전송 시 SSL/TLS 암호화 적용 및 파일별 접근 로그(Audit Trail) 기록 | 상 |
| **QR-004** | 인증 및 권한 | RBAC 모델을 적용하여 역할별(관리자, 팀원, 외부) 상세 접근 권한 제어 | 상 |

### 3.3 호환성 및 이식성 (Compatibility & Portability)
| ID | 품질 특성 | 요구사항 세부 내용 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **QR-005** | **호환성** | Chrome, Safari, Edge 최신 버전에서 동일한 UI/UX 및 기능 보장 | 상 |
| **QR-006** | **이식성** | Windows 10/11 및 macOS(Sonoma 이상) 환경의 웹 브라우저에서 충돌 없이 동작 | 상 |
