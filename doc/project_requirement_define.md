## 1. 서론

### 1.1 문서 목적 및 범위
본 문서는 조직 내 분산된 파일 공유 방식을 개선하고 협업 효율성을 높이기 위한 '클라우드 파일 공유 시스템(미니 드라이브)'의 요구사항을 정의하고 시스템이 갖추어야 할 기능적 요소와 성능, 보안 등 기능적, 비기능적 요소를 상세히 기술하여 개발 지표로 삼는 것을 목표함

### 1.2 대상 시스템 개요
#### 1.2.1 프로젝트 정의
사용자가 파일을 중앙 서버에 업로드하여 관리하고, 팀원 및 외부 협력 업체와 안전하게 공유할 수 있는 웹 기반 협업 플랫폼을 구축

#### 1.2.2 주요 기능 설명
| ID | 설명 |
| :--- | :--- |
| **F01** | 웹 브라우저를 통한 파일 업로드 및 다운로드 (문서, 이미지, 영상 등) |
| **F02** | 다단계 폴더 구조 생성 및 관리 기능 |
| **F03** | 사용자별/그룹별 권한 기반 파일 및 폴더 공유 |
| **F04** | 파일명, 날짜, 유형 등에 따른 고속 검색 |
| **F05** | 파일 수정 이력 관리 및 이전 버전 복원 |

### 1.3 용어 정의
| 용어 | 설명 |
| :--- | :--- |
| **RBAC** | 역할 기반 접근 제어 (Role-Based Access Control) |
| **공유 링크** | 외부 사용자가 파일을 다운로드할 수 있도록 생성된 고유 URL |

## 2. 요구사항

### 2.1 기능적 요구사항(Functional Requirement)

#### 2.1.1 계정 및 관리 기능
| 분류 | 요구사항 | 우선순위 |
| :--- | :--- | :--- |
| **FR-001** | 사용자는 이메일과 비밀번호를 통해 시스템에 로그인 | 상 |
| **FR-002** | 관리자는 사용자 계정을 생성, 삭제하고 저장 공간을 할당 | 상 |

#### 2.1.2 파일 및 폴더 관리 기능
| 분류 | 요구사항 | 우선순위 |
| :--- | :--- | :--- |
| **FR-003** | 사용자는 웹 브라우저를 통해 다양한 유형의 파일을 업로드/다운로드 | 상 |
| **FR-004** | 사용자는 폴더를 생성하고 파일을 이동시키거나 이름을 변경 | 중 |
| **FR-005** | 삭제된 파일은 일정 기간 복구가 가능하도록 휴지통 기능을 제공 | 중 |

#### 2.1.3 공유 및 협업 기능
| 분류 | 요구사항 | 우선순위 |
| :--- | :--- | :--- |
| **FR-006** |파일 공유 시 보기, 수정, 댓글 권한을 세분화하여 설정 가능 | 상 |
| **FR-007** | 외부 사용자를 위해 만료 기간 설정이 가능한 공유 링크를 생성 | 상 |

#### 2.1.4 검색 및 버전 관리 기능
| 분류 | 요구사항 | 우선순위 |
| :--- | :--- | :--- |
| **FR-008** | 파일명, 업로드 날짜, 사용자, 파일 유형 필터를 통한 검색을 지원 | 상 |
| **FR-009** | 수정된 파일의 이전 버전을 목록으로 확인하고 복원 가능 | 중 |

---

### 2.2 비기능적 요구사항(Non-Functional Requirement)

#### 1) 운영 및 성능 요구사항
| 분류 | 요구사항 | 우선순위 |
| :--- | :--- | :--- |
| **NFR-001** | 약 200명의 사용자가 동시 접속해도 안정적으로 동작 | 상 |
| **NFR-002** | 파일 검색 및 다운로드 요청에 대해 지연 없는 빠른 응답 속도를 유지 | 상 |
| **NFR-003** | 별도의 프로그램 설치 없이 웹 브라우저를 통해 접근 가능 | 상 |

#### 2) 보안 요구사항
| 분류 | 요구사항 | 우선순위 |
| :--- | :--- | :--- |
| **NFR-004** | 모든 데이터 전송 시 SSL/TLS 암호화를 적용하여 정보 유출 방지 | 상 |
| **NFR-005** | 권한 기반 접근 제어(RBAC)를 통해 인가되지 않은 파일 접근을 차단 | 상 |

---

### 2.3 인터페이스 요구사항
* **웹 브라우저 호환성**: 특정 설치 프로그램 없이 웹 브라우저(Chrome, Safari, Edge 등)를 통해 접근 가능해야 하며, 브라우저별 렌더링 차이를 최소화해야 함
* **직관적인 파일 조작**: 파일 업로드 시 '드래그 앤 드롭(Drag & Drop)' 기능을 지원하고, 폴더 이동이나 이름 변경 시 직관적인 팝업 또는 인라인 편집 UI를 제공
