# 클라우드 파일 공유 시스템(미니드라이브)

이 레포지토리는 클라우드 기반 파일 공유 및 협업 시스템인 '미니 드라이브' 프로젝트를 담고 있습니다.

## 폴더 구조 및 역할
* 'doc/': 프로젝트 관련 문서가 저장됩니다. (요구사항 명세서, 이해관계자 분석 등)
* 'src/': 시스템 구현을 위한 소스 코드가 저장됩니다. (추후 빌드 방법 명시 예정)

## 브랜치 관리
* **main**: 배포 가능한 수준의 안정적인 코드가 관리되는 기본 브랜치입니다.
