### 과제2 (프로젝트 IV: 프로젝트 관리 계획서 작성)
* **위치** `doc/project_management_plan.md`
* **주요내용**: 조직 내 파일 관리의 효율성과 보안성을 높이기 위해 Agile(SCRUM) 방법론을 기반으로 구축하는 웹 기반 중앙 집중식 클라우드 파일 공유 시스템 개발 계획서

**1. 프로젝트 개요 및 목표**
정의: 협업 환경에서 다양한 프로젝트 자료를 한곳에서 관리하는 시스템
배경: 기존 이메일/메신저 공유 방식의 문제점(버전 관리 어려움, 검색 시간 과다, 보안 위험)을 해결
목표: 중앙 관리, 간편한 업로드/다운로드, 팀원 및 외부인과의 안전한 파일 공유, 빠른 검색 기능 제공을 목표

**2. 개발 계획 및 방법론**
방법론: 유연한 요구사항 대응을 위한 SCRUM 모델과 유지보수에 용이한 객체지향 방법론을 채택
주요 활동(WBS): 요구분석 → 시스템 설계(DB, 아키텍처) → 구현(웹/서버/DB) → 테스트 → 배포 및 인도로 구성
기술 스택: 웹 기반 서비스(React/Vue, Node.js/Spring Boot) 및 RDBMS(MySQL 등)를 활용

**3. 팀 구성 및 운영**
조직: 수평적 팀 구조를 지향하며, 팀장(PM)과 DB/웹 구현 담당 팀원으로 구성
운영: 데일리 스크럼(매일 15분)과 주간 보고를 통해 진행 상황 및 장애 요인을 상시 공유

**4. 품질 및 산출물 관리**
변경 관리: 변경 요청서(CR)를 통한 공식적인 절차를 거쳐 반영
버전 관리: GitHub을 소스 코드 저장소로 사용하며, 문서 및 소프트웨어에 대해 정해진 명명 규칙을 적용하여 버전을 관리
최종 산출물: 계획서, 요구사항 정의서, 설계서, 소스 코드, 테스트 보고서, 사용자 가이드 등을 포함

**5. 리스크 관리**
팀원 변경이나 프로젝트 주제 변경과 같은 고위험 리스크에 대비해 작업량 조절, 팀원 간 화합, 명확한 요구사항 설계 등의 대응 방안을 수립
