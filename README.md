# 클라우드 파일 공유 시스템 (미니 드라이브)

본 프로젝트는 조직 내 분산된 파일 공유 방식을 개선하고, 협업 효율성 및 보안성을 높이기 위한 중앙 집중식 클라우드 파일 관리 시스템인 **'미니 드라이브'** 구축을 목표로 함

## 📂 폴더 구조 및 역할
* `doc/` : 프로젝트 관련 문서가 저장됨. (요구사항 명세서, 이해관계자 분석 등) 
* `src/` : 시스템 구현을 위한 소스 코드가 저장됨 (추후 빌드 방법 명시 예정) 

## 🌿 브랜치 관리
* `main`: 배포 가능한 수준의 안정적인 코드가 관리되는 기본 브랜치

## 📄 주요 과제 결과물

### 과제1 (프로젝트 II: 요구사항 분석 및 이해관계자 기대치 정리)
* **위치**: `doc/requirements.md`
* **주요 내용**: 각 Stakeholder별 요구사항 및 소프트웨어 품질 요소 정의

| 이해관계자 | 핵심 가치 (Quality Attributes) | 주요 기대치 |
| :--- | :--- | :--- |
| **사용자** | **사용성 (Usability)** | 웹 기반의 직관적 UI, 다단계 폴더 관리, 빠른 파일 검색 |
| **개발자** | **가용성 (Availability)** | 200명 동시 접속 안정성 보장, 시스템 확장성 고려 [cite: 85, 86, 95] |
| **관리자** | **보안성 (Security) & 신뢰성** | 권한 기반 접근 제어(RBAC), 데이터 전송 암호화, 버전 관리 및 복구 |

### 과제2 (프로젝트 IV: 프로젝트 관리 계획서 작성)
* **위치** `doc/project_management_plan.md`
* **주요내용**: 조직 내 파일 관리의 효율성과 보안성을 높이기 위해 Agile(SCRUM) 방법론을 기반으로 구축하는 웹 기반 중앙 집중식 클라우드 파일 공유 시스템 개발 계획서

### 과제3 (프로젝트 VI: 요구사항 정의서 작성)
* **위치** `doc/project_requirement_define.md`
* **주요내용**: 조직 내 분산된 파일 공유 방식을 개선하고 협업 효율성을 높이기 위한 '클라우드 파일 공유 시스템(미니 드라이브)'의 요구사항을 정의하고 시스템이 갖추어야 할 기능적 요소와 성능, 보안 등 기능적, 비기능적 요소를 상세히 기술

---

### 과제4 (프로젝트 VII: 요구사항 분석서에 따른 산출물 작성)
* **위치** `doc/UML_Design.md`
